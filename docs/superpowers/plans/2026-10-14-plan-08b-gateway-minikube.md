# Plan 8B — Gateway: minikube Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove Plan 8A end to end on the local minikube cluster with the same chart that will deploy to Azure, the way a client app uses the system. The smoke test talks only to auth-svc's public API and the gateway's WebSocket, through the ingress, with real access tokens: three users connect (the gateway answers 4006 until the worker has relayed a device), become contacts by request and by invite, chat, edit, read and delete over the WebSocket, see a group request refused, see only the profiles they may see, see an expired token and a token for another audience refused, and finally see a revoked device and a password reset close their sockets with 4003 and 4001 and their old tokens refused. message-svc's `Messaging` API, which acts for whatever user and device it is given, takes calls only with the gateway's own internal token, generated by the chart. `test-chart.ps1` has 31 checks.

**Architecture:** The smoke test drops its gRPC client of message-svc (`messaging.rs`) and its Redis listener (`kicks.rs`); a new `socket.rs` holds a connection as an app does — identified with the device's token, frames sent and awaited in order, frames that arrive while waiting for another kept — and a new `tokens.rs` signs the two tokens the gateway must refuse with auth-svc's own key and key id, so that only the claim under test is wrong. In message-svc, `InternalToken::messaging` guards `Messaging` as the worker's and auth-svc's tokens guard `Accounts` and `Directory`; the gateway puts `authorization: Bearer <token>` on every call through a tonic interceptor. In the chart the Secret gets `messaging-token` (48 random characters, generated once and kept with `lookup`), given to the gateway and message-svc only; the smoke Pod loses `--message-svc` and the Redis URL and gets `PUSH_SMOKE_SIGNING_KEY` from the Secret's `auth-signing-key`. No database or script changes: message-svc's migration 0003 and the new Secret key arrive on the upgrade. Spec: `docs/superpowers/specs/2026-10-11-push-messenger-design.md` §2, §7, §11, §12; roadmap "Running locally on minikube".

**Tech Stack:** Docker (BuildKit), minikube 1.34 (Kubernetes 1.31, docker driver, ingress addon), kubectl, Helm 3.16, PowerShell 7 and bash. `push-smoke` now uses `base64` 0.22 (in the workspace) and no longer `redis`, `tonic` or `prost`.

## Key rules the configuration must preserve

- **One token per internal API, given only to its caller.** `accounts-token` reaches
  message-svc and the worker, `directory-token` message-svc and auth-svc, and
  `messaging-token` message-svc and the gateway. All three are generated on install, kept
  on upgrades (`lookup`), must differ (message-svc refuses to start otherwise) and reach
  containers only through `secretKeyRef`.
- **No secret in git, in a ConfigMap or in a Pod's arguments.** The smoke test reads
  auth-svc's signing key from the Secret through its environment and never prints it or the
  tokens it signs (`Target`'s `Debug` redacts it).
- **The smoke test is a client.** It reaches auth-svc and the gateway only through the
  ingress, like an app; only the DEV ONLY mailbox is read from the worker directly.
- **The smoke test never prints bodies, tokens, invite codes or token-bearing URLs**: it
  reports ids, seqs, close codes, error codes and timings only, bounds every wait (10 s a
  step, 30 s for what waits for the worker) and the whole run (180 s).

## Decisions made for this plan

These were settled while writing the plan and verified on minikube. Plan 8A's decisions and
the owner's earlier decisions apply. Do not reopen any of this during execution.

1. **The smoke test uses the WebSocket for everything a client app does.** Requests,
   edits, deletes and reads go over the gateway; contact events, receipts and read positions
   are awaited on the sockets; kicks are awaited as close codes (4003, 4001) rather than on
   Redis; a device not relayed yet is reconnected after 4006 with backoff (250 ms doubling
   to 2 s, so at most about 18 attempts in 30 s, under the `Identify` limit of 30 a minute).
   After each kick the old token is tried again and must be refused: 4003 for the revoked
   device (message-svc refuses it), 4001 for Bob's token from before his reset (the
   password-reset check of Plan 8A).
2. **Refused tokens are signed with auth-svc's own key.** An expired token (two minutes past
   `exp`, beyond the 60 s leeway) and one for another audience, both with auth-svc's key and
   `kid`, so the gateway's `exp` and `aud` checks are what refuses them, not the signature.
   The DEV ONLY smoke Pod (rendered only in dev mode) gets the signing key from the Secret
   through its environment; in exchange it no longer gets the Redis URL, and it never reaches
   message-svc. The Rust tests of Plan 8A cover the other refusals (signature, `kid`,
   algorithm, missing claims).
3. **The group request is refused in the smoke test** (`NOT_AVAILABLE`), as the owner
   decided; message-svc's group support stays tested in Rust.
4. **A connection buffers what it is not waiting for.** The gateway pushes contact events,
   receipts and other entries at any time; the smoke test keeps frames it is not waiting for,
   so the order of its waits cannot lose one. An `Error` frame no wait accepts fails the run.
5. **The Messaging token works like the other two.** `PUSH_MESSAGING_TOKEN`: 32 to 256
   visible ASCII characters, different from the Accounts and Directory tokens, compared in
   constant time; without it message-svc warns at start-up and refuses every `Messaging`
   call (`UNAUTHENTICATED`). The gateway requires it, marks the header value sensitive and
   never shows it in `Debug`. Plan 11 adds a NetworkPolicy on top.
6. **Sockets are pinged before the kicks.** A connection the test opened early may have been
   quiet for a while; a `Ping` keeps it clear of the gateway's 75 s idle timeout.

Create `crates/push-smoke/src/socket.rs` (decision 4):

```rust
//! The smoke test's WebSocket connections, as a client app holds them: identified with the
//! device's access token, frames sent and awaited in order. Frames that arrive while the
//! test waits for another are kept, so nothing the gateway pushes is lost to the order of
//! the waits.

use std::collections::VecDeque;
use std::time::{Duration, Instant};

use anyhow::{Context, bail};
use futures_util::{SinkExt, StreamExt};
use push_proto::v1::frame::Body;
use push_proto::v1::{self, Identify, Ping, request, response};
use push_proto::{decode_frame, encode_frame};
use tokio::net::TcpStream;
use tokio_tungstenite::tungstenite::Message;
use tokio_tungstenite::tungstenite::client::IntoClientRequest;
use tokio_tungstenite::tungstenite::http::HeaderValue;
use tokio_tungstenite::{MaybeTlsStream, WebSocketStream, connect_async};

use crate::{CONNECT_TIMEOUT, STEP_TIMEOUT, Target, step};

/// How long a closing handshake may take; the test has passed by then.
const CLOSE_TIMEOUT: Duration = Duration::from_secs(2);

/// An identified connection.
pub(crate) struct Conn {
    name: &'static str,
    socket: WebSocketStream<MaybeTlsStream<TcpStream>>,
    /// Frames received while the test waited for something else.
    pending: VecDeque<Body>,
    next_request: u64,
}

/// What became of an `Identify`.
pub(crate) enum Identified {
    Ready(Box<Conn>, v1::Ready),
    /// The gateway closed the connection with this code.
    Closed(u16),
}

/// Connects to the gateway, through the ingress, and identifies with `token`.
pub(crate) async fn identify(
    target: &Target,
    name: &'static str,
    token: &str,
) -> anyhow::Result<Identified> {
    let deadline = Instant::now() + CONNECT_TIMEOUT;
    let mut socket = loop {
        let mut request = target.socket_url.as_str().into_client_request()?;
        if let Some(host) = &target.host {
            request
                .headers_mut()
                .insert("Host", HeaderValue::from_str(host)?);
        }
        match tokio::time::timeout(STEP_TIMEOUT, connect_async(request)).await {
            Ok(Ok((socket, _))) => break socket,
            Ok(Err(error)) if Instant::now() < deadline => {
                step(&format!("{name} cannot connect yet ({error}); retrying"));
            }
            Ok(Err(error)) => {
                return Err(error).context(format!("connect {name} to {}", target.socket_url));
            }
            Err(_) => bail!("connecting {name} timed out"),
        }
        tokio::time::sleep(Duration::from_secs(2)).await;
    };
    let identify = Body::Identify(Identify {
        token: token.to_owned(),
    });
    socket
        .send(Message::Binary(encode_frame(identify).into()))
        .await
        .context("send Identify")?;
    loop {
        let message = tokio::time::timeout(STEP_TIMEOUT, socket.next())
            .await
            .map_err(|_| anyhow::anyhow!("{name}: no answer to Identify within {STEP_TIMEOUT:?}"))?
            .with_context(|| format!("{name}: the connection ended before Ready"))?
            .with_context(|| format!("{name}: the connection failed before Ready"))?;
        match message {
            Message::Binary(bytes) => match decode_frame(&bytes).context("decode a frame")? {
                Body::Ready(ready) => {
                    let conn = Conn {
                        name,
                        socket,
                        pending: VecDeque::new(),
                        next_request: 0,
                    };
                    return Ok(Identified::Ready(Box::new(conn), ready));
                }
                _ => bail!("{name}: expected Ready, got another frame"),
            },
            Message::Close(frame) => {
                return Ok(Identified::Closed(
                    frame.map_or(1005, |frame| frame.code.into()),
                ));
            }
            _ => {}
        }
    }
}

impl Conn {
    pub async fn send(&mut self, body: Body) -> anyhow::Result<()> {
        self.socket
            .send(Message::Binary(encode_frame(body).into()))
            .await
            .with_context(|| format!("{}: send a frame", self.name))
    }

    /// The first frame `wanted` accepts, kept or new, within the step timeout; the others
    /// are kept. An `Error` frame that no wait accepts fails the test.
    pub async fn wait_for(
        &mut self,
        waiting_for: &str,
        wanted: impl Fn(&Body) -> bool,
    ) -> anyhow::Result<Body> {
        if let Some(index) = self.pending.iter().position(&wanted) {
            return Ok(self.pending.remove(index).expect("the index is in range"));
        }
        let deadline = tokio::time::Instant::now() + STEP_TIMEOUT;
        loop {
            let message = tokio::time::timeout_at(deadline, self.socket.next())
                .await
                .map_err(|_| {
                    anyhow::anyhow!("{}: no {waiting_for} within {STEP_TIMEOUT:?}", self.name)
                })?
                .with_context(|| format!("{}: the connection ended", self.name))?
                .with_context(|| format!("{}: the connection failed", self.name))?;
            let body = match message {
                Message::Binary(bytes) => decode_frame(&bytes).context("decode a frame")?,
                Message::Close(frame) => bail!(
                    "{}: closed with {:?} while waiting for {waiting_for}",
                    self.name,
                    frame.map(|frame| u16::from(frame.code))
                ),
                _ => continue,
            };
            if wanted(&body) {
                return Ok(body);
            }
            if let Body::Error(error) = &body {
                bail!(
                    "{}: an error while waiting for {waiting_for}: {:?} ({})",
                    self.name,
                    error.code(),
                    error.message
                );
            }
            self.pending.push_back(body);
        }
    }

    /// Sends a request and returns its answer: the `Response` body, or the `Error`.
    pub async fn ask(
        &mut self,
        body: request::Body,
        what: &str,
    ) -> anyhow::Result<Result<response::Body, v1::Error>> {
        self.next_request += 1;
        let request_id = self.next_request;
        let request = v1::Request {
            request_id,
            body: Some(body),
        };
        self.send(Body::Request(request)).await?;
        let answer = self
            .wait_for(what, |frame| match frame {
                Body::Response(response) => response.request_id == request_id,
                Body::Error(error) => error.request_id == Some(request_id),
                _ => false,
            })
            .await?;
        match answer {
            Body::Response(response) => Ok(Ok(response
                .body
                .with_context(|| format!("{what}: an empty answer"))?)),
            Body::Error(error) => Ok(Err(error)),
            _ => unreachable!("the wait accepts only answers"),
        }
    }

    /// Sends a request that must succeed; its answer.
    pub async fn request(
        &mut self,
        body: request::Body,
        what: &str,
    ) -> anyhow::Result<response::Body> {
        match self.ask(body, what).await? {
            Ok(answer) => Ok(answer),
            Err(error) => bail!("{what}: {:?} ({})", error.code(), error.message),
        }
    }

    /// A `Ping` answered by a `Pong`: the connection is alive and every frame sent before
    /// it was handled (the gateway handles a connection's frames in order).
    pub async fn ping(&mut self) -> anyhow::Result<()> {
        self.send(Body::Ping(Ping {})).await?;
        self.wait_for("a Pong", |frame| matches!(frame, Body::Pong(_)))
            .await?;
        Ok(())
    }

    /// Waits up to `timeout` for the gateway to close the connection; its close code.
    pub async fn closed(&mut self, waiting_for: &str, timeout: Duration) -> anyhow::Result<u16> {
        let deadline = tokio::time::Instant::now() + timeout;
        loop {
            let message = tokio::time::timeout_at(deadline, self.socket.next())
                .await
                .map_err(|_| {
                    anyhow::anyhow!("{}: no {waiting_for} within {timeout:?}", self.name)
                })?;
            match message {
                Some(Ok(Message::Close(frame))) => {
                    return Ok(frame.map_or(1005, |frame| frame.code.into()));
                }
                Some(Ok(_)) => {}
                Some(Err(error)) => {
                    bail!(
                        "{}: the connection failed before {waiting_for}: {error}",
                        self.name
                    )
                }
                None => bail!("{}: the connection ended without {waiting_for}", self.name),
            }
        }
    }

    /// Closes the connection from the client's side.
    pub async fn close(mut self) {
        let _ = tokio::time::timeout(CLOSE_TIMEOUT, self.socket.close(None)).await;
    }
}
```

Create `crates/push-smoke/src/tokens.rs` (decision 2):

```rust
//! Access tokens the gateway must refuse, signed with auth-svc's own key so that only the
//! claim under test is wrong: one that expired, one for another audience. The smoke test
//! reads the key from the deployment's Secret; it never prints it or the tokens.

use std::time::{SystemTime, UNIX_EPOCH};

use anyhow::Context;
use base64::Engine;
use base64::engine::general_purpose::STANDARD;
use jsonwebtoken::{Algorithm, EncodingKey, Header};
use serde_json::json;
use uuid::Uuid;

/// The PKCS#8 v1 prefix of an Ed25519 private key; the 32-byte seed follows it.
const PKCS8_ED25519_PREFIX: [u8; 16] = [
    0x30, 0x2e, 0x02, 0x01, 0x00, 0x30, 0x05, 0x06, 0x03, 0x2b, 0x65, 0x70, 0x04, 0x22, 0x04, 0x20,
];

/// Signs tokens as auth-svc does, with its key and key id.
pub(crate) struct Forger {
    key: EncodingKey,
    kid: String,
}

impl Forger {
    /// `signing_key` is auth-svc's seed, base64 of 32 bytes; the key id is taken from a
    /// token auth-svc issued, so the gateway finds the key.
    pub fn new(signing_key: &str, issued: &str) -> anyhow::Result<Self> {
        let seed = STANDARD
            .decode(signing_key.trim())
            .ok()
            .filter(|seed| seed.len() == 32)
            .context("the signing key is not base64 of 32 bytes")?;
        let mut der = PKCS8_ED25519_PREFIX.to_vec();
        der.extend_from_slice(&seed);
        let kid = jsonwebtoken::decode_header(issued)
            .context("decode an access token's header")?
            .kid
            .context("auth-svc's access token has no kid")?;
        Ok(Self {
            key: EncodingKey::from_ed_der(&der),
            kid,
        })
    }

    /// A token for `user` on `device` that expired `expired_s` seconds ago (negative: that
    /// expires in as many seconds), for `audience`.
    pub fn token(&self, user: Uuid, device: Uuid, expired_s: i64, audience: &str) -> String {
        let now = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map_or(0, |since| since.as_secs() as i64);
        let exp = now - expired_s;
        let claims = json!({
            "sub": user,
            "device_id": device,
            "email_verified": true,
            "exp": exp,
            "iat": exp - 900,
```

```rust
//! push-smoke: the end-to-end smoke test of a running push-messenger.
//!
//! Against a deployment it:
//!
//! 1. enrolls Alice, Bob and Carol through auth-svc's public API: each signs up, waits for
//!    the verification email that the worker's log sender delivers to the DEV ONLY
//!    mailbox, verifies with its link, signs in, registers a device, checks the access
//!    token against the JWKS and refreshes it;
//! 2. connects each device's WebSocket with its access token, as an app does, and waits
//!    for `Ready`: until the worker has relayed the device to message-svc the gateway
//!    closes with 4006 ("not ready yet"), and the smoke test reconnects with backoff;
//! 3. over the WebSocket: Alice asks Bob to be a contact, Bob's socket hears the request
//!    and Bob accepts; Carol redeems Alice's invite; Alice opens the direct conversation;
//!    auth-svc shows Alice the profiles of Bob and Carol, and Bob none of Carol's;
//! 4. Alice sends a message and gets her `SendAck`; Bob's socket delivers it and Bob acks;
//! 5. Alice edits the message and Bob's socket delivers the edit; Bob reads up to the
//!    message, his socket hears his new read position and Alice's the receipt, and her
//!    listing shows it read; a group request is refused (groups are not offered to apps
//!    in the first release); Alice deletes the message, Bob's socket delivers the delete,
//!    and Bob's history holds the message erased;

//!    (4002, 4001);

//!    socket with 4003 and Bob's with 4001, and refuses their old tokens from then on.
//!

//! smoke test needs auth-svc's signing key (from the deployment's Secret) for step 6.

/// Where the deployment is.
#[derive(Clone, PartialEq, Eq)]
pub struct Target {

/// The usage line of the `push-smoke` binary.
pub const USAGE: &str = "usage: push-smoke --auth <url> --mailbox <url> --socket <ws-url> [--host <host>], with auth-svc's signing key in PUSH_SMOKE_SIGNING_KEY";

impl Target {
    /// Reads `--auth`, `--mailbox`, `--socket` and `--host` from `args`; each one missing
    /// there is read from `env` (`PUSH_SMOKE_AUTH_URL`, `PUSH_SMOKE_MAILBOX_URL`,
    /// `PUSH_SMOKE_SOCKET_URL`, `PUSH_SMOKE_HOST`). The signing key comes from
    /// `PUSH_SMOKE_SIGNING_KEY` only: a secret never belongs in a Pod's arguments.
    pub fn parse(
        args: impl IntoIterator<Item = String>,
        env: impl Fn(&str) -> Option<String>,
    ) -> Result<Self, String> {
        let (mut auth_url, mut mailbox_url, mut socket_url, mut host) = (None, None, None, None);
        let mut args = args.into_iter();
        while let Some(flag) = args.next() {
            let slot = match flag.as_str() {
                "--auth" => &mut auth_url,
                "--mailbox" => &mut mailbox_url,
                "--socket" => &mut socket_url,
                "--host" => &mut host,
                other => return Err(format!("unknown argument {other:?}; {USAGE}")),
            };
            *slot = Some(args.next().ok_or_else(|| format!("{flag} needs a value"))?);
        }
        let required = |value: Option<String>, what: &str, variable: &str| {
            value
                .or_else(|| env(variable))
                .filter(|value| !value.is_empty())
                .ok_or_else(|| format!("{what} is required; {USAGE}"))
        };
        Ok(Self {
            auth_url: required(
                auth_url,
                "--auth or PUSH_SMOKE_AUTH_URL",
                "PUSH_SMOKE_AUTH_URL",
            )?,
            mailbox_url: required(
                mailbox_url,
                "--mailbox or PUSH_SMOKE_MAILBOX_URL",
                "PUSH_SMOKE_MAILBOX_URL",
            )?,
            socket_url: required(
                socket_url,
                "--socket or PUSH_SMOKE_SOCKET_URL",
                "PUSH_SMOKE_SOCKET_URL",
            )?,
            host: host
                .or_else(|| env("PUSH_SMOKE_HOST"))
                .filter(|host| !host.is_empty()),
            signing_key: required(None, "PUSH_SMOKE_SIGNING_KEY", "PUSH_SMOKE_SIGNING_KEY")?,
        })
    }
}

/// Runs the smoke test, printing each step. Fails at the first step that does not
/// complete within 10 s (30 s for what waits for the worker).
pub async fn run(target: &Target) -> anyhow::Result<()> {
    let started = Instant::now();
    let auth = auth::Auth::connect(target, STEP_TIMEOUT).await?;
    let alice = auth.enroll("alice").await?;
    let bob = auth.enroll("bob").await?;
    let carol = auth.enroll("carol").await?;
    let forger = Forger::new(&target.signing_key, &alice.access_token)?;

    let mut alice = Client::connect(target, "alice", alice).await?;
    let mut bob = Client::connect(target, "bob", bob).await?;
    let mut carol = Client::connect(target, "carol", carol).await?;
    let conversation = befriend(&auth, &mut alice, &mut bob, &mut carol).await?;
    let (sent, client_msg_id) = chat(&mut alice, &mut bob, &conversation).await?;
    let message = Message {
        conversation: &conversation,
        sent: &sent,
        client_msg_id: &client_msg_id,
    };
    change(&mut alice, &mut bob, &carol, &message).await?;
    refuse_tokens(target, &auth, &forger, &alice).await?;
    kick(target, &auth, bob, carol).await?;
    alice.conn.close().await;
    step(&format!("PASS in {} ms", started.elapsed().as_millis()));
    Ok(())
}

impl Client {
    /// Connects and identifies with the device's access token. Until the worker has
    /// relayed the device to message-svc the gateway closes with 4006, which means "try
    /// again shortly", never a sign-out: reconnects with backoff, 250 ms doubling to 2 s.
    async fn connect(
        target: &Target,
        name: &'static str,
        enrolled: auth::Enrolled,
    ) -> anyhow::Result<Self> {
        let started = Instant::now();
        let mut not_ready = 0;
        let mut backoff = Duration::from_millis(250);
        let (conn, ready) = loop {
            match identify(target, name, &enrolled.access_token).await? {
                Identified::Ready(conn, ready) => break (conn, ready),
                Identified::Closed(4006) if started.elapsed() < WORKER_TIMEOUT => {
                    not_ready += 1;
                }
                Identified::Closed(4006) => bail!(
                    "the worker did not relay {name}'s device to message-svc within {WORKER_TIMEOUT:?}"
                ),
                Identified::Closed(code) => bail!("{name}'s Identify was closed with {code}"),
            }
            tokio::time::sleep(backoff).await;
            backoff = (backoff * 2).min(Duration::from_secs(2));
        };
        if ready.user_id != id_bytes(enrolled.user) || ready.device_id != id_bytes(enrolled.device)
        {
            bail!("{name}'s Ready names another user or device than the token");
        }
        step(&format!(
            "{name} connected with the access token (Ready, heartbeat {} ms) once the worker had relayed device {}: {not_ready} \"not ready yet\" closes (4006) in {} ms",
            ready.heartbeat_ms,
            enrolled.device,
            started.elapsed().as_millis()
        ));
        Ok(Self {
            name,
            user: enrolled.user,
            device: enrolled.device,
            email: enrolled.email,
            access_token: enrolled.access_token,
            conn,
        })
    }
}

/// Contacts by request and by invite, the direct conversation, and the profiles each may
/// see, all over the WebSocket. Returns the direct conversation of Alice and Bob.
async fn befriend(
    auth: &auth::Auth<'_>,
    alice: &mut Client,
    bob: &mut Client,
    carol: &mut Client,
) -> anyhow::Result<Vec<u8>> {
    let ask = request::Body::ContactRequest(ContactRequest {
        user_id: id_bytes(bob.user),
    });
    let asked = alice.conn.request(ask, "alice's contact request").await?;
    let pending = Contact {
        user_id: id_bytes(bob.user),
        state: ContactState::RequestedOut.into(),
    };
    if asked != response::Body::Contact(pending) {
        bail!("alice's contact request was answered with something else");
    }
    let heard = contact_event(alice.user, ContactState::RequestedIn);
    bob.conn
        .wait_for("the request's ContactEvent", |frame| *frame == heard)
        .await?;
    let accept = request::Body::ContactAccept(ContactAccept {
        user_id: id_bytes(alice.user),
    });
    bob.conn.request(accept, "bob's accept").await?;
    let accepted = contact_event(bob.user, ContactState::Accepted);
    alice
        .conn
        .wait_for("the acceptance's ContactEvent", |frame| *frame == accepted)
        .await?;
    step(
        "alice asked bob to be a contact; bob's socket heard it (ContactEvent), bob accepted and alice's socket heard that",
    );

    let create = request::Body::CreateInvite(CreateInvite {
        expires_in_s: 600,
        max_uses: 1,
    });
    let response::Body::Invite(invite) = alice.conn.request(create, "alice's invite").await? else {
        bail!("alice's invite was answered with something else");
    };
    let redeem = request::Body::RedeemInvite(RedeemInvite { code: invite.code });
    let redeemed = carol.conn.request(redeem, "carol's redeem").await?;
    let creator = InviteRedeemed {
        user_id: id_bytes(alice.user),
    };
    if redeemed != response::Body::InviteRedeemed(creator) {
        bail!("carol's redeem was answered with something else");
    }
    step("carol redeemed alice's invite: they are contacts");

    let open = request::Body::OpenDirect(OpenDirect {
        peer_user_id: id_bytes(bob.user),
    });
    let response::Body::DirectOpened(opened) = alice.conn.request(open, "open the chat").await?
    else {
        bail!("opening the chat was answered with something else");
    };
    step("alice opened the direct conversation with bob");

    let mut seen = auth
        .profiles(&alice.access_token, &[bob.user, carol.user])
        .await?;
    seen.sort();
    let mut contacts = vec![bob.user, carol.user];
    contacts.sort();
    if seen != contacts {
        bail!("auth-svc showed alice the profiles of {seen:?}, not bob's and carol's");
    }
    // Asking for alice too proves the endpoint answers bob at all.
    if auth
        .profiles(&bob.access_token, &[alice.user, carol.user])
        .await?
        != [alice.user]
    {
        bail!("auth-svc did not show bob exactly alice's profile; carol shares nothing with him");
    }
    step(
        "auth-svc shows alice the profiles of her contacts bob and carol, and bob none of carol's",
    );
    Ok(opened.conversation_id)
}

fn contact_event(user: Uuid, state: ContactState) -> Body {
    Body::ContactEvent(ContactEvent {
        user_id: id_bytes(user),
        state: state.into(),
    })
}

/// Alice sends a message and Bob receives and acks it: Alice's `SendAck` and the
/// message's `client_msg_id`.
async fn chat(
    alice: &mut Client,
    bob: &mut Client,
    conversation: &[u8],
) -> anyhow::Result<(SendAck, Vec<u8>)> {
    let client_msg_id = id_bytes(Uuid::now_v7());
    let text = format!("hello from push-smoke {}", Uuid::now_v7());
    let sent_at = Instant::now();
    alice
        .conn
        .send(Body::Send(Send {
            client_msg_id: client_msg_id.clone(),
            conversation_id: conversation.to_vec(),
            content_type: ContentType::Text.into(),
            body: text.clone().into_bytes(),
            client_ts: None,
        }))
        .await?;
    let Body::SendAck(ack) = alice
        .conn
        .wait_for(
            "alice's SendAck",
            |frame| matches!(frame, Body::SendAck(ack) if ack.client_msg_id == client_msg_id),
        )
        .await?
    else {
        unreachable!("the wait accepts only SendAck");
    };
    step(&format!(
        "alice got SendAck seq={} after {} ms",
        ack.seq,
        sent_at.elapsed().as_millis()
    ));

    let entry = delivered(&mut bob.conn, conversation, ack.seq, "bob's Deliver").await?;
    if entry.body.as_deref() != Some(text.as_bytes()) || entry.sender_id != id_bytes(alice.user) {
        bail!("bob received the wrong message: {}", describe(&entry));
    }
    step(&format!(
        "bob got Deliver seq={} after {} ms",
        entry.seq,
        sent_at.elapsed().as_millis()
    ));

    bob.conn
        .send(Body::Ack(Ack {
            conversation_id: conversation.to_vec(),
            seq: entry.seq,
        }))
        .await?;
    bob.conn.ping().await?;
    step("bob acked; the gateway answered the following Ping");
    Ok((ack, client_msg_id))
}

/// The message Alice sent in her direct conversation with Bob.
struct Message<'a> {
    conversation: &'a [u8],
    sent: &'a SendAck,
    client_msg_id: &'a [u8],
}

/// Alice edits the message, Bob reads it, a group request is refused and Alice deletes
/// the message; Bob's socket delivers every entry they add.
async fn change(
    alice: &mut Client,
    bob: &mut Client,
    carol: &Client,
    message: &Message<'_>,
) -> anyhow::Result<()> {
    let Message {
        conversation,
        sent,
        client_msg_id,
    } = *message;
    let edit_id = id_bytes(Uuid::now_v7());
    alice
        .conn
        .send(Body::Edit(Edit {
            client_msg_id: edit_id.clone(),
            conversation_id: conversation.to_vec(),
            target: Some(edit::Target::TargetMessageId(sent.message_id.clone())),
            body: b"hello, edited".to_vec(),
            client_ts: None,
        }))
        .await?;
    let edited = acked(&mut alice.conn, &edit_id, "the edit's SendAck").await?;
    if edited.seq != sent.seq + 1 {
        bail!("the edit got seq {}, not {}", edited.seq, sent.seq + 1);
    }
    let entry = delivered(&mut bob.conn, conversation, edited.seq, "the edit").await?;
    if entry.kind() != EntryKind::Edit || entry.target_seq != Some(sent.seq) {
        bail!(
            "bob's socket delivered {} instead of the edit",
            describe(&entry)
        );
    }
    step(&format!(
        "alice edited her message; bob's socket delivered the edit (seq {})",
        edited.seq
    ));

    bob.conn
        .send(Body::ReadUpTo(ReadUpTo {
            conversation_id: conversation.to_vec(),
            seq: sent.seq,
        }))
        .await?;
    bob.conn
        .wait_for("bob's ReadPosition", |frame| {
            matches!(frame, Body::ReadPosition(read)
                if read.conversation_id == conversation && read.read_seq == sent.seq)
        })
        .await?;
    alice
        .conn
        .wait_for("the read receipt", |frame| {
            matches!(frame, Body::Receipt(receipt)
                if receipt.conversation_id == conversation
                    && matches!(&receipt.positions,
                        Some(receipt::Positions::Direct(direct)) if direct.read_seq == sent.seq))
        })
        .await?;
    let list = request::Body::ListConversations(ListConversations::default());
    let response::Body::Conversations(listed) = alice.conn.request(list, "alice's listing").await?
    else {
        bail!("alice's listing was answered with something else");
    };
    let read = listed
        .conversations
        .iter()
        .find(|summary| summary.conversation_id == conversation)
        .and_then(|summary| match &summary.receipts {
            Some(conversation_summary::Receipts::Direct(receipts)) => Some(receipts.peer_read_seq),
            _ => None,
        });
    if read != Some(sent.seq) {
        bail!(
            "alice's listing shows bob read up to {read:?}, not {}",
            sent.seq
        );
    }
    step(
        "bob read the message; his socket heard his ReadPosition, alice's the Receipt, and her listing shows it read",
    );

    let group = request::Body::CreateGroup(CreateGroup {
        title: "Smoke".to_owned(),
        member_ids: vec![id_bytes(bob.user), id_bytes(carol.user)],
    });
    match alice.conn.ask(group, "a group request").await? {
        Err(error) if error.code() == ErrorCode::NotAvailable => {}
        Err(error) => bail!("a group request was refused with {:?}", error.code()),
        Ok(_) => bail!("a group was created, though groups are not offered to apps"),
    }
    step("alice's group request was refused (NOT_AVAILABLE): groups are not offered to apps");

    let delete_id = id_bytes(Uuid::now_v7());
    alice
        .conn
        .send(Body::Delete(Delete {
            client_msg_id: delete_id.clone(),
            conversation_id: conversation.to_vec(),
            target: Some(delete::Target::TargetClientMsgId(client_msg_id.to_vec())),
        }))
        .await?;
    let deleted = acked(&mut alice.conn, &delete_id, "the delete's SendAck").await?;
    if deleted.seq != edited.seq + 1 {
        bail!("the delete got seq {}, not {}", deleted.seq, edited.seq + 1);
    }
    let entry = delivered(&mut bob.conn, conversation, deleted.seq, "the delete").await?;
    if entry.kind() != EntryKind::Delete || entry.target_seq != Some(sent.seq) {
        bail!(
            "bob's socket delivered {} instead of the delete",
            describe(&entry)
        );
    }
    let fetch = request::Body::FetchHistory(FetchHistory {
        conversation_id: conversation.to_vec(),
        before_seq: None,
        limit: 0,
    });
    let response::Body::History(page) = bob.conn.request(fetch, "bob's history").await? else {
        bail!("bob's history was answered with something else");
    };
    match page.entries.as_slice() {
        [message] if message.seq == sent.seq && message.deleted && message.body.is_none() => {}
        entries => bail!(
            "bob's history is not the erased message alone ({} entries)",
            entries.len()
        ),
    }
    step(&format!(
        "alice deleted her message; bob's socket delivered the delete (seq {}) and his history holds it erased",
        deleted.seq
    ));
    Ok(())
}

/// Tokens signed with auth-svc's key and naming Alice's device, but expired or for
/// another audience, are refused: 4002 (refresh, then reconnect) and 4001 (sign in again).
async fn refuse_tokens(
    target: &Target,
    auth: &auth::Auth<'_>,
    forger: &Forger,
    alice: &Client,
) -> anyhow::Result<()> {
    let audience = auth.expected_audience();
    // Expired two minutes ago: past the gateway's 60 s leeway.
    let expired = forger.token(alice.user, alice.device, 120, &audience);
    let elsewhere = "wss://elsewhere.invalid/v1/socket";
    let other_audience = forger.token(alice.user, alice.device, -600, elsewhere);
    for (token, expected, what) in [
        (expired, 4002, "an expired token"),
        (other_audience, 4001, "a token for another audience"),
    ] {
        match identify(target, "alice", &token).await? {
            Identified::Closed(code) if code == expected => {}
            Identified::Closed(code) => bail!("{what} was closed with {code}, not {expected}"),
            Identified::Ready(..) => bail!("the gateway accepted {what}"),
        }
    }
    step(
        "the gateway refused a token that had expired (4002) and one for another audience (4001), both signed with auth-svc's key",
    );
    Ok(())
}

/// Carol revokes her device and Bob resets his password; once the worker relays them
/// the gateway closes their sockets (4003 for the revocation, 4001 for the reset) and
/// refuses their old tokens.
async fn kick(
    target: &Target,
    auth: &auth::Auth<'_>,
    mut bob: Client,
    mut carol: Client,
) -> anyhow::Result<()> {
    // Both sockets have been quiet; a Ping keeps them clear of the idle timeout.
    carol.conn.ping().await?;
    bob.conn.ping().await?;

    let started = Instant::now();
    auth.revoke_device(&carol.access_token, carol.device)
        .await?;
    let code = carol.conn.closed("carol's kick", WORKER_TIMEOUT).await?;
    if code != 4003 {
        bail!("carol's socket was closed with {code}, not 4003 (revoked)");
    }
    let waited = started.elapsed();
    match identify(target, carol.name, &carol.access_token).await? {
        Identified::Closed(4003) => {}
        Identified::Closed(code) => bail!("carol's revoked device was closed with {code}"),
        Identified::Ready(..) => bail!("the gateway still accepts carol's revoked device"),
    }
    step(&format!(
        "carol revoked her device; after the worker relayed it the gateway closed her socket with 4003 ({} ms) and refuses her token",
        waited.as_millis()
    ));

    let started = Instant::now();
    auth.reset_password(&bob.email).await?;
    let code = bob.conn.closed("bob's kick", WORKER_TIMEOUT).await?;
    if code != 4001 {
        bail!("bob's socket was closed with {code}, not 4001 (sign in again)");
    }
    let waited = started.elapsed();
    match identify(target, bob.name, &bob.access_token).await? {
        Identified::Closed(4001) => {}
        Identified::Closed(code) => {
            bail!("bob's token from before the reset was closed with {code}")
        }
        Identified::Ready(..) => {

/// Waits for the `SendAck` of the edit or delete sent with `client_msg_id`.
async fn acked(conn: &mut Conn, client_msg_id: &[u8], what: &str) -> anyhow::Result<SendAck> {
    let frame = conn
        .wait_for(
            what,
            |frame| matches!(frame, Body::SendAck(ack) if ack.client_msg_id == client_msg_id),
        )
        .await?;
    let Body::SendAck(ack) = frame else {
        unreachable!("the wait accepts only SendAck");
    };
    Ok(ack)
}

/// Waits for the `Deliver` of `seq` in `conversation`.
async fn delivered(
    conn: &mut Conn,
    conversation: &[u8],
    seq: i64,
    waiting_for: &str,
) -> anyhow::Result<Deliver> {
    let frame = conn
        .wait_for(waiting_for, |frame| {
            matches!(frame, Body::Deliver(entry)
                if entry.seq == seq && entry.conversation_id == conversation)
        })
        .await?;
    let Body::Deliver(entry) = frame else {
        unreachable!("the wait accepts only Deliver");
    };
    Ok(entry)
}
```
